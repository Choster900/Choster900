## About me

I am a Software Development Engineering graduate focused on building scalable backend platforms, microservices, mobile applications and cloud-native solutions.

- Backend development with **Java, Spring Boot, Node.js, NestJS and TypeScript**
- Microservices, REST APIs, authentication, messaging and distributed architectures
- Mobile development with **React Native and Expo**
- Web development with **Angular, Vue, Nuxt and React**
- Cloud and DevOps with **GCP, AWS, Docker, Kubernetes, Nginx and CI/CD**
- Databases including **PostgreSQL, MySQL, MongoDB and Redis**
- Experience with blockchain-based document verification using **SHA-256 and Ethereum smart contracts**
